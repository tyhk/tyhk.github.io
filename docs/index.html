Linux内核Copy Fail & Dirty Frag双漏洞提权危机

Linux内核近期爆發重大安全漏洞危機。首個為「CopyFail」（CVE-2026-31431），由Theori研究團隊揭露，為9年老漏洞（自2017年起），影響幾乎所有主流Linux發行版，包括Ubuntu 24.04 LTS、Amazon Linux 2023、RHEL 10.1、SUSE 16及Rocky Linux 9.7。漏洞位於内核複製機制，無需競爭條件即可可靠本地權限提升（LPE），PoC腳本微小、無痕跡、不改檔案、不依賴額外軟體，甚至可逃脫容器隔離。4月30日公布，5月4日CISA列入已知利用漏洞目錄，命令美國聯邦機構於5月15日前修補。Debian、Ubuntu、AlmaLinux、SUSE、Fedora、CloudLinux已出補丁，RHEL用戶仍待修補。 僅兩週後，第二漏洞「Dirty Frag」曝光（來源[3]，The Record報導），位於CopyFail相同内核區域，同樣允許低權限用戶輕鬆利用，為兩週內第二重大LPE bug，細節尚未全揭。 其他來源提及相關内核更新，如Miracle Linux kernel-5.14.0-570.12.1.el9_6（エラータID: AXSA:2025-10392:38），修補多項CVE（如CVE-2024-36013藍牙、CVE-2024-43871 devres等），但未直接涉及CopyFail。Hacker News討論供應鏈攻擊風險，Spotify播客提及Arch Linux等動態。整體凸顯Linux内核供應鏈與老漏洞威脅，呼籲即時更新。

Dirty Frag漏洞影響主流Linux獲Root

Linux内核“Dirty Frag”本地提权漏洞近日曝光，由韩国资安研究员Hyunwoo Kim发现并公开PoC。该漏洞链结合xfrm-ESP模块（自commit cac2661c53f3起）和RxRPC模块（自commit 2dc334f1a63a起）两个页缓存写入缺陷，无需竞争条件或命名空间权限，仅一条命令即可让非特权用户获root权限，影响2017年后几乎所有主流发行版。 来源[1]（腾讯云，2026年5月）详述漏洞机制：xfrm-ESP允许向任意可读文件（如setuid二进制）页缓存写4字节受控数据，RxRPC无需默认加载即可触发；影响Ubuntu 24.04.4、RHEL 10、CentOS 10、AlmaLinux 10、Fedora 44、openSUSE Tumbleweed；暂无CVE编号，高风险，呼吁立即排查。 [2]（iThome，5月8日）强调低权限用户直接root，Hyunwoo Kim首公开漏洞链。 [3]（BigGo财经，2026年5月10日）突出自2017年起“绝大多数”Linux系统瞬间root，截至报道无补丁，紧急性最高。 [4]（CSDN）指algif_aead加密接口漏洞，一命令root主流版，与[1]重合但强调加密接口。 LinkedIn链接（标题：Warning New Critical Linux Vulnerability Dirty）疑为英文预警，补充“critical”评级，但无独特细节。多源一致无补丁，差异在影响范围（[1]最详尽具体版本）和日期（[2]最早5/8），均无官方CVE，建议用户禁用模块或等补丁。

FCC延長外國路由器固件更新豁免至2029

# 美國FCC放寬外國製造路由器和無人機軟體更新禁令綜合摘要 美國聯邦通信委員會（FCC）於5月10日發布禁令更新，放寬對外國製造Wi-Fi路由器和無人機的軟體更新限制。根據多個科技媒體報導，FCC將軟體更新期限延長至2029年1月1日，相比之前的限制大幅延期。 具體而言，原先FCC的禁令僅允許外國路由器廠商在2027年3月1日前進行軟體更新，無人機廠商則在2027年1月1日前更新。此次放寬將兩類設備的更新期限統一延至2029年1月1日。 美國政府認為外國製造的無人機和路由器可能對國內網路基礎設施構成安全風險，因此實施禁令。然而，這兩類產品已被數百萬消費者廣泛使用，若廠商無法繼續提供軟體更新，現有設備將因無法修復漏洞而更容易遭受駭客攻擊。 在更新類型方面，FCC允許發布I類小型更新和旨在「減輕美國消費者傷害」的II類更新。但涉及修改無線電發射頻率和輸出功率的III類更新仍被禁止。 值得注意的是，雖然現有設備獲得延期保護，但未來新開發或即將上市的外國製造Wi-Fi路由器與無人機仍然被禁止進入美國市場。此舉反映出美國在維護網路安全與保護現有消費者權益之間的平衡考量。
