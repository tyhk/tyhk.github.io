# Canvas平台數據外洩事件綜合摘要 全球知名線上學習管理系統Canvas的母公司Instructure於5月7日證實遭黑客組織ShinyHunters入侵。黑客聲稱竊取全球8,809間教育機構共2.75億名用戶的個人資料，涉及3.65TB數據，並於登入頁面發出勒索警告，要求受影響機構在5月12日前進行和解談判，否則將公開所有資料。 外洩資料包括用戶姓名、電郵地址、學號及用戶間訊息內容。Instructure確認目前無證據顯示密碼、出生日期、政府身份識別資訊或財務資料外洩。安全漏洞源於Canvas平台上的「教師免費服務」(Free-For-Teacher)帳戶設定缺陷，該服務已被關閉。 香港方面，私隱專員公署截至5月8日下午6時接獲5間教育機構通報，包括香港理工大學（約42,000名學生及員工）、香港建造學院（約2,500名學生及員工）、香港科技大學、香港演藝學院及香港教育城。另外，三育書院及香港醫學專科學院亦疑似受影響。受影響機構合計逾4.4萬名師生資料外洩。 Canvas為全球高等院校學習管理系統市場領導者，佔有率約41%，全球活躍用戶逾3,000萬人。此事件涉及哈佛大學、史丹福大學等知名學府，成為截至2026年5月有記錄以來規模最大的教育界網絡安全事故。 網絡安全專家提醒用戶啟動雙重認證等防護措施，並警惕可能的二次詐騙風險。香港網絡安全事故協調中心已發出警示，建議受影響機構檢視系統安全。

伊朗MuddyWater假冒Chaos勒索軟件間諜攻擊

# Rapid7：Chaos勒索軟體與伊朗MuddyWater關聯分析 Rapid7於2026年5月6日發布報告《Muddying the Tracks: The State-Sponsored Shadow Behind Chaos Ransomware》，揭露一起2026年初的入侵事件實為伊朗政府支持的MuddyWater（又名Seedworm、Static Kitten、Mango Sandstorm）所策劃的虛假旗幟行動。該組織隸屬於伊朗情報安全部（MOIS），藉由冒充Chaos勒索軟體附屬機構來掩蓋地緣政治間諜活動。 攻擊始於Microsoft Teams社交工程，攻擊者透過螢幕共享與員工互動，進行認證資訊竊取、MFA操縱，並快速轉向使用合法帳戶進行內部存取。受害者被誘騙將密碼輸入本地文件（credentials.txt、cred.txt），並修改MFA設定以包含攻擊者控制的設備。 技術指標顯示MuddyWater的特徵包括：使用代碼簽署憑證「Donald Gay」驗證惡意軟體、moonzonet[.]com C2基礎設施、pythonw.exe程式碼注入技術，以及互動式Teams會話進行認證竊取。Rapid7以中等信心度將此事件歸因於MuddyWater。 值得注意的是，攻擊者繞過傳統勒索軟體工作流程，未進行檔案加密，而是專注於資料外洩與透過DWAgent和AnyDesk等遠端管理工具建立長期持久性。儘管發布了竊取的資料進行勒索，但主要目標顯然是間諜活動而非財務獲利。 MuddyWater過往曾在2025年底針對以色列組織使用Qilin勒索軟體進行類似偽裝。此次轉向Chaos品牌可能是為進一步降低歸因風險。該策略反映國家贊助入侵活動與犯罪手法的融合，利用勒索軟體掩蓋真實的網路間諜目標。

# 台灣詐騙集團轉接技術升級分析 ## 綜合摘要 台灣刑事局近期破獲多起利用電話轉接技術規避防詐警示的詐騙案件，顯示詐團手法已大幅升級。 **核心詐騙手法演變：** 詐騙集團為規避政府與電信業者合作推動的「+886」國際來電7秒語音警示系統，研發出「繞道轉接」新招。他們利用網路電話從境外進線，先竄改發話號碼連接到國內「人頭門號」，再設定「指定轉接」功能將詐騙電話轉給被害人，使被害人完全聽不到防詐警示，誤以為是國內正常來電。 **重點案例：** 刑事局電信偵查大隊於2024年9月25日在台中七期高級商辦攻堅，逮捕游姓主嫌等4人。該機房詐騙9名被害人，詐騙金額高達1,500萬元。詐團成員冒充國家通訊傳播委員會、中華電信等公務機關，謊稱被害人遭冒名申辦門號涉及詐欺案，再假冒檢警以代管財產名義誘騙交付財物。 **最新升級手法：** 詐團已進化至「金融接管」模式。新北市劉姓上班族今年1月遭詐，詐團誘導其輸入「**21*」指令加上指定門號完成來電轉接設定，將通訊權限完全移交詐團。此舉使銀行查證電話直接落入詐團手中，防護機制全面失效，導致被害人股票遭盜賣損失百萬元。 **警方提醒：** 司法機關絕不會要求民眾設定來電轉接或提供網銀密碼。民眾應警惕輸入「**21*」或下載不明App等關鍵紅線，可撥打165反詐騙專線查詢。

# 澳洲小企業網絡安全認知與準備不足的綜合分析 澳洲小企業面臨嚴重的網絡安全認知與行動落差。根據多項研究，超過一半的澳洲小企業（52-60%）不認為自己是網絡攻擊目標，然而實際上三分之一的小企業已經歷過網絡事件。這種認知偏差導致準備不足——60%的企業沒有網絡安全計劃，平均每月僅花費兩小時進行防護，五分之一企業甚至完全不投入時間。 全球數據顯示小企業實為高風險群體，佔所有攻擊的43%。澳洲小企業的脆弱性表現在多個方面：僅44%的少於50人企業擁有專門安全預算；79%的個體經營者缺乏應急計劃；38%在遭攻擊後未採取任何行動。2022-23年度，小企業平均網絡犯罪成本達46,000澳元。 攻擊類型方面，釣魚郵件佔38%、惡意軟體佔24%、冒充可信聯絡人佔24%。儘管67%的企業主因大公司遭攻擊而提高警覺，但這未轉化為實際防護行動。38%的企業仍認為網絡安全對中大型企業更重要。 積極信號是86%的小企業對簡化、可行的網絡安全方案表示興趣，顯示市場存在改善潛力。然而，61%企業未定期討論網絡安全，進一步加劇風險。澳洲政府與Optus、Coalition等機構的研究均強調，改變小企業的認知與投資態度為當務之急。

警政署警示電話轉接詐騙新手法

# 電話轉接詐騙手法分析摘要 根據警政署公布的案例，詐騙集團已演進出結合「來電轉接」與「金融盜刷」的新型態犯罪模式，危害程度遠超以往。 **詐騙手法流程：** 詐騙集團首先冒充165反詐騙專線或檢警人員來電，謊稱受害人身分證遭盜用涉及刑案或洗錢案件，製造緊急感迫使受害者配合。隨後轉接給自稱「主任」的詐騙分子，以嚴厲口吻威脅若不配合將被視為共犯，進而要求受害者加入特定LINE帳號、提供網銀帳密、下載不明App並綁定信用卡。 最關鍵的一步是誘導受害者輸入「**21*」加指定門號設定來電轉接功能。此舉使銀行異常交易查證電話全數轉往詐團手中，詐團冒充本人回應，短短2天內即可盜刷多家銀行信用卡。一起案例中，受害者損失高達366萬元，包括信用卡盜刷260萬元及證券帳戶套現105萬元。 **警方提醒重點：** - 政府機關絕不會透過電話要求提供網銀帳密或監管帳戶 - 檢警不會直接轉接電話，政府機關來電會顯示號碼 - 聽到「身分冒用」、「洗錢案」、「監管帳戶」等關鍵字應立即掛斷 - 遇到要求下載不明App、綁定信用卡或設定來電轉接的要求應立即停止 - 市內電話若被盜轉，接聽時僅響一聲，撥出時會先聽到「嘟、嘟」兩聲 **防範建議：** 接獲不明來電應保持理性謹慎，直撥165反詐騙專線求證。加強大樓門禁管理，防止詐騙分子假借電信公司人員身分盜接電話線路。若發現電話異常，應立即撥打中華電信「123」客服處理。

Zara遭ShinyHunters竊取20萬用戶資料

Zara母公司Inditex（IDEXY）近日遭駭客組織ShinyHunters資料竊取，引發資安事件。根據IT之家援引Have I Been Pwned分析（來源[1]及ithome連結），事件影響19.74萬名用戶，洩露資料包括電子郵件地址、地理位置、購買記錄、產品SKU、訂單ID及客服工單內容，這些資訊恐助長釣魚攻擊風險。 Inditex官方聲明（來源[2]，cmoney.tw）澄清，該資料庫不含敏感客戶個人資料，如通訊地址、帳號密碼或銀行卡細節，僅為非核心資訊。公司已確認事件，但強調無重大客戶隱私外洩。 多來源比較顯示，IT之家及Have I Been Pwned強調洩露規模（197,400人）及具體項目（如地理位置、SKU），突出潛在釣魚威脅；Inditex則淡化影響，否認敏感資料外流。無明確事件日期，但ShinyHunters被指為主導駭客。整體事件凸顯時尚零售業資安漏洞，建議受影響用戶監控郵件並加強帳密防護。
