Canvas數據洩露2.75億教育用戶

# Canvas平台數據外洩事件綜合摘要 全球知名線上學習管理系統Canvas的母公司Instructure於5月7日證實遭黑客組織ShinyHunters入侵。黑客聲稱竊取全球8,809間教育機構共2.75億名用戶的個人資料，涉及3.65TB數據，並於登入頁面發出勒索警告，要求受影響機構在5月12日前進行和解談判，否則將公開所有資料。 外洩資料包括用戶姓名、電郵地址、學號及用戶間訊息內容。Instructure確認目前無證據顯示密碼、出生日期、政府身份識別資訊或財務資料外洩。安全漏洞源於Canvas平台上的「教師免費服務」(Free-For-Teacher)帳戶設定缺陷，該服務已被關閉。 香港方面，私隱專員公署截至5月8日下午6時接獲5間教育機構通報，包括香港理工大學（約42,000名學生及員工）、香港建造學院（約2,500名學生及員工）、香港科技大學、香港演藝學院及香港教育城。另外，三育書院及香港醫學專科學院亦疑似受影響。受影響機構合計逾4.4萬名師生資料外洩。 Canvas為全球高等院校學習管理系統市場領導者，佔有率約41%，全球活躍用戶逾3,000萬人。此事件涉及哈佛大學、史丹福大學等知名學府，成為截至2026年5月有記錄以來規模最大的教育界網絡安全事故。 網絡安全專家提醒用戶啟動雙重認證等防護措施，並警惕可能的二次詐騙風險。香港網絡安全事故協調中心已發出警示，建議受影響機構檢視系統安全。

FBI警告俄駭入侵路由器，CISO速加固

FBI於近日發出緊急警告，呼籲美國用戶立即強化家用路由器安全，以防範俄羅斯軍事情報機構GRU（俄羅斯總參謀部情報總局）發動的網路攻擊。根據CNET報導（無具體發布日期），FBI特別點名GRU Unit 29155為攻擊主體，該單位自2020年起已入侵超過11,000台路由器，涵蓋美國及全球逾100個國家。攻擊目標包括Ubiquiti、Netgear、ASUS及TP-Link等品牌路由器，駭客透過預設或已知弱密碼入侵，植入惡意軟體，竊取網路流量並用於後續間諜或破壞活動。 FBI建議5項立即防護步驟：1.更改預設管理員密碼，使用強密碼（至少12字元，含大小寫、數字、符號）；2.啟用路由器韌體自動更新，或手動檢查最新版本；3.停用遠端管理（Remote Management）功能，避免外部存取；4.檢查並移除未知裝置，確保僅授權設備連線；5.考慮升級至支援WPA3加密的新路由器。CNET強調，此攻擊不限美國，全球用戶均受威脅，FBI已透過CISA（網路安全與基礎設施安全局）發布技術警報，詳列受影響型號如Ubiquiti EdgeRouter及Netgear ProSAFE。 報導無其他來源比較，但FBI聲明突出GRU自2022年烏克蘭衝突以來活動加劇，近期掃描逾17,000台美國路由器。專家提醒，路由器為家庭網路門戶，入侵恐導致資料外洩或DDoS攻擊。用戶應即刻執行上述步驟，降低風險。

加州CPPA年內啟動資安審計，企業速備戰

加州隱私保護機構（CPPA）依據2020年加州消費者隱私權利法（CPRA），於2026年1月1日起施行CCPA網絡安全審計規則（Cal. Code Regs. tit. 11, §§ 7120–7124），要求涵蓋企業每年進行獨立網絡安全審計（CSA），並向州政府認證結果。此規則將18項特定網絡安全控制領域（如數據加密、存取管理等）定義為「合理安全」基準，不需待違規事件觸發，即主動評估，預計成執法與法庭調查標竿，甚至適用非正式範圍企業。 SWK Technologies指出，中小企業（SMB）首需評估適用性，其管理服務提供者（MSP）可協助準備；CPPA標準化監管影響評估（SRIA）文件詳述規則涵蓋：(1)更新既有CCPA規範；(2)釐清保險公司遵守時點；(3)CSA執行頻率（每年或重大變動時）；(4)風險評估（RA）要求；(5)消費者存取權運作化。企業須經網頁入口年度或間歇提交文件，CPPA IT部門將開發系統接收。與聯邦VA規範（VAAR 852）比較，後者強調承包商IT資源現場檢查、年度隱私訓練證書及行為規則簽署，側重政府合約；無明顯差異，但CCPA更廣泛適用民間企業。 San Diego市文件僅提財務審計，無網絡安全細節。企業應及早盤點控制缺口，預防2026年執法風險。

警政署警示電話轉接詐騙新手法

# 電話轉接詐騙手法分析摘要 根據警政署公布的案例，詐騙集團已演進出結合「來電轉接」與「金融盜刷」的新型態犯罪模式，危害程度遠超以往。 **詐騙手法流程：** 詐騙集團首先冒充165反詐騙專線或檢警人員來電，謊稱受害人身分證遭盜用涉及刑案或洗錢案件，製造緊急感迫使受害者配合。隨後轉接給自稱「主任」的詐騙分子，以嚴厲口吻威脅若不配合將被視為共犯，進而要求受害者加入特定LINE帳號、提供網銀帳密、下載不明App並綁定信用卡。 最關鍵的一步是誘導受害者輸入「**21*」加指定門號設定來電轉接功能。此舉使銀行異常交易查證電話全數轉往詐團手中，詐團冒充本人回應，短短2天內即可盜刷多家銀行信用卡。一起案例中，受害者損失高達366萬元，包括信用卡盜刷260萬元及證券帳戶套現105萬元。 **警方提醒重點：** - 政府機關絕不會透過電話要求提供網銀帳密或監管帳戶 - 檢警不會直接轉接電話，政府機關來電會顯示號碼 - 聽到「身分冒用」、「洗錢案」、「監管帳戶」等關鍵字應立即掛斷 - 遇到要求下載不明App、綁定信用卡或設定來電轉接的要求應立即停止 - 市內電話若被盜轉，接聽時僅響一聲，撥出時會先聽到「嘟、嘟」兩聲 **防範建議：** 接獲不明來電應保持理性謹慎，直撥165反詐騙專線求證。加強大樓門禁管理，防止詐騙分子假借電信公司人員身分盜接電話線路。若發現電話異常，應立即撥打中華電信「123」客服處理。
