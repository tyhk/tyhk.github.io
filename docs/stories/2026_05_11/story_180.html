逾5千Vibe Coding App資料外洩危機

Critical New Cybersecurity Incident

Vibe Coding（氛圍編程）應用程式資安危機頻傳，逾5000個AI生成工具暴露海量資料。RedAccess研究發現5000個公開AI編碼應用中，近2000個洩私密數據，40%暴露敏感資訊如醫療記錄、財務資料及財富500強內部文件（虎嗅，2026）。Escape.tech去年10月掃描5600個vibe coding應用，逾2000高危漏洞、400個API金鑰外洩、175醫療/銀行個資案例，今年3月獲Balderton 1800萬美元A輪融資（虎嗅）。 常見漏洞包括SQL Injection、XSS、CSRF及硬編碼金鑰，Bloomberg引研究指45% AI碼有安全缺口，非技術用戶難察覺（Blocktempo）。恆遠數位案例：SaaS API無驗證洩用戶Email，兩週無日誌追蹤（Foreverwebs）。心理健康App獨案：Oversecured掃10款Android App（下載1470萬次），1575漏洞（54高風險），含Intent濫用、明文API、Firebase洩密，治療紀錄暗網售價逾1000美元/筆（iThome）。 Anthropic Claude Code 2026/3/31 npm源碼外洩59.8MB，影響51萬用戶，駭客散惡意程式；Claude App Builder 4/12截圖洩，瞄準Lovable市場（Brickverse、Trendmicro）。Apple嚴審vibe coding App，封Replit/Vibecode更新，憂AI誘導惡碼或隱私洩（UDN、Unwire）。整體趨勢：AI代理漏洞恐助攻擊，GitHub/LangChain框架亦曝（Trendmicro）。
