2026年05月12日

AI計算框架Ray漏洞遭大規模攻擊 數千服務器淪陷

Critical New Cybersecurity Incident

# 2026年AI網絡威脅綜合分析摘要 根據多份安全報告，2026年AI驅動的網絡攻擊已成為現實威脅。Check Point報告揭示，2025年全球企業平均每週遭受1,968次攻擊，較2023年增長70%。其中89%的組織曾遭遇高風險AI提示詞攻擊，平均每41個提示詞就有1個被歸類為高風險。 **AI攻擊的主要特徵包括：**自動化程度大幅提升，攻擊者利用AI生成多樣化惡意軟體變種、個性化釣魚郵件和深度偽造內容。Symantec警告，AI帶來的威脅不是讓攻擊「更聰明」，而是「更多」，企業面臨前所未有的攻擊量爆發。Cloudflare指出，AI正從「輔助工具」轉變為自主攻擊器，威脅者透過「氛圍編程」大幅提升攻擊速度與規模。 **新型威脅包括：** Prompt Injection成為AI系統重要風險；AI語音釣魚與語音克隆技術日趨逼真；代理型AI（Agentic AI）打破攻擊技術門檻；供應鏈攻擊加劇，如Anthropic的Claude Code CLI原始碼外洩超512,000行，朝鮮黑客劫持Axios項目植入惡意軟體。 **基礎設施弱點擴大：** 未受監控的邊緣設備、VPN和物聯網系統成為攻擊者的「中繼點」。趨勢科技識別六大威脅方向：AI威脅、APT威脅、企業威脅、雲威脅、勒索軟體與漏洞，強調威脅變得更快速、更自動化、更具協同性。 **防禦挑戰：** 企業防禦策略需從「追求完美檢測」轉向「假設已被入侵」的零信任模式。2026年的核心安全挑戰是如何抵禦智能、自適應且具自主能力的威脅，企業需加強供應鏈監控、邊緣設備管理，並升級AI系統的安全防護機制。
